🚀 Migrasi Katalog Game ke Google Sheets (GAS)

Alat ini akan mengirimkan seluruh data game PC & PS2 lokal dari file data/games.json, pc_games.js, dan ps2_games.js ke Google Sheet Anda melalui Google Apps Script Web App API.

Langkah Persiapan:
  1. Buka file gas_backend_template.gs di project ini.
  2. Tempel kode tersebut ke Google Apps Script (Extensions > Apps Script di Google Sheets Anda).
  3. Deploy sebagai Web App dengan Akses "Anyone".
  4. Masukkan URL Web App hasil deploy di bawah ini.
